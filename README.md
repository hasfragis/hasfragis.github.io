# hasfragis.github.io

The public landing page for **Hasfragis**, digital evidence integrity: https://hasfragis.github.io

Plain HTML, CSS and a little JavaScript; no build step. The Hasfragis source code itself is private.

- `index.html`: the page
- `assets/site.css`: styles (the dashboard's R2 look)
- `assets/site.js`: the screenshot tabs
- `assets/line-globe.js`: the turning line globe in the hero
- `assets/img/`: dashboard screenshots (fictional demo data), team avatars, logo
- `assets/fonts/`: Oswald, Poppins and JetBrains Mono (SIL Open Font License 1.1, see `LICENSE-OFL.txt`)

Publishing: Settings → Pages → Deploy from a branch → `main` / `(root)`.
